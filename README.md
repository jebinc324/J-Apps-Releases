## Important download safety notes

Files are published for public access, but **publication and matching SHA-256 hashes do not establish malware-free status, installation safety, compatibility, functionality, or a signed/verified publisher identity**. Check the package's expected device and application version. Download files only from sources you trust. Review installation permissions before using an Android APK or engineering tool.

The initial migration preserved all 57 files from the previous public release, with each filename, size and SHA-256 digest checked against the original inventory. For future updates, independently review the asset being published and update the Just24Things catalogue metadata.
